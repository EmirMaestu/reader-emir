# Hoja · Lector EPUB

Lector de EPUB para celular y PC. Un solo archivo `index.html`; los libros se guardan en el navegador.

## Publicar en GitHub Pages
1. Sube el contenido de esta carpeta a la raíz del repo (rama `main`).
2. En GitHub: Settings → Pages → Source: "Deploy from a branch" → `main` / `/ (root)` → Save.
3. En un minuto queda en `https://emirmaestu.github.io/reader-emir/`.
